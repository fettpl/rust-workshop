The local catalog has 175 lessons in 45 modules, 178 concepts, 130 blank-page tasks, 7 memory traces, 318 source entries and thirteen Cargo projects. The course assumes programming basics and teaches Rust from zero. The Unsafe/FFI module adds four lessons on raw-pointer preconditions, disjoint regions, `#[repr(C)]` validation and an RAII FFI handle. The new fuzz evidence module adds four lessons, eight gates, four blank tasks and four independent retrievals; Mini grep stores a stable replay separately from the nightly campaign.

Ma osiem bramek, cztery blank-page tasks i cztery kodowe retrievals. Brak przypiętego binarium/bazy cargo-deny jest jawnie oznaczony jako `unsupported/infrastructure`, więc decyzja wydania pozostaje hold; snapshot nie jest live feedem, SBOM-em ani publikacją.

Zintegrowany katalog Unsafe/FFI ma lokalne testy treści, integrację pakietu i dedykowany verifier stable/MSRV. `ffi-buffer-workshop` jest dziesiątym autorskim pakietem: zawiera checked-in C ABI, bezpieczny wrapper, testy natywnej granicy i safety ledger. Miri nie jest raportowane: obecny pakiet celowo przekracza granicę kompilowanego C i alokatora, a repozytorium nie ma reprodukowalnego, wspieranego przebiegu Miri dla tego fixture.

Etap `service-operations` jest 39. modułem i jedenastym projektem. Cztery lekcje mają osiem bramek, cztery blank-page i cztery powtórki kodowe; sprawdzają bounded admission, allowlistę skorelowanej telemetryki, readiness/drain oraz diagnozę z niewystarczającym dowodem. `service-operations-workshop` przypina Tokio 1.53.1, zawiera pięć testów kontraktowych, sześć kontrolowanych mutantów, threat model i runbook. Stable oraz exact Rust 1.85.0 porównują wygenerowane archiwa przed testami Cargo; E2E sprawdza mapę, wznowienie, pobranie i offline cache. Pakiet jest autorskim fixture dydaktycznym: nie uruchamia kodu ucznia ani importu i nie deklaruje produkcyjnego backendu telemetrycznego, cancellation arbitralnego blocking code ani pełnej gotowości operacyjnej.
