# Trusted Tokio fixture profile

This package fixes the dependencies used to verify repository-authored Tokio lessons. It is not an execution service and never accepts learner drafts, imports, paths or manifests. Tokio is pinned to 1.54.1 with `macros`, `rt`, `sync`, `time`, `test-util`, `io-util` and `net`; tokio-stream is pinned to 0.1.19 without default features. The profile verifies runtime, flow-control, I/O, stream, blocking-work and TCP fixtures. Its network preflight keeps a listener bound to `127.0.0.1:0` alive through connect/accept, request half-close and response. It never contacts a public host.

The feature choice is backed by the [Tokio 1.54.1 manifest](https://raw.githubusercontent.com/tokio-rs/tokio/tokio-1.54.1/tokio/Cargo.toml): `test-util` depends on `rt`, `sync` and `time`. Tokio 1.54.1 requires Rust 1.85 and fixes RUSTSEC-2026-0386 and RUSTSEC-2026-0384. The authored fixtures do not use the affected `AsyncFd` constructors. This current native profile replaces the earlier 1.53.1 profile; historical receipts and legacy metadata keep their original versions and identity. A read-only 2026-09-12 Playground-manifest inspection recorded Tokio 1.53.1, not this patched profile, and does not prove the current deployed Playground. No external runner POST was used for this upgrade. See [the runner boundary](../../../docs/runner.md).

The verifier copies this manifest and Cargo.lock into a new temporary directory, writes reviewed lesson sources there and invokes fixed Cargo commands with --offline --locked. Maintainers may run the dedicated verifier with --fetch once to populate Cargo's dependency cache from this exact lockfile. The browser continues to use the fixed external Playground prelude and does not send this manifest or select a dependency profile.
