# Trusted Tokio fixture profile

This package fixes the dependencies used to verify repository-authored Tokio lessons. It is not an execution service and never accepts learner drafts, imports, paths or manifests. Tokio is pinned to 1.53.1 with `macros`, `rt`, `sync`, `time`, `test-util`, `io-util` and `net`; tokio-stream is pinned to 0.1.19 without default features. The profile verifies runtime, flow-control, I/O, stream, blocking-work and TCP fixtures. Its network preflight keeps a listener bound to `127.0.0.1:0` alive through connect/accept, request half-close and response. It never contacts a public host.

The feature choice is backed by read-only inspection: Tokio's [1.53.1 Cargo manifest](https://raw.githubusercontent.com/tokio-rs/tokio/tokio-1.53.1/tokio/Cargo.toml) defines `test-util` in terms of `rt`, `sync` and `time`. The [generated Rust Playground compiler manifest](https://github.com/rust-lang/rust-playground/blob/main/compiler/base/Cargo.toml) also pins Tokio to 1.53.1 and includes the required runtime, I/O and network features. Source inspection is not proof of execution on the currently deployed Playground; no external runner POST was used for this milestone. See [the runner boundary](../../../docs/runner.md).

The verifier copies this manifest and Cargo.lock into a new temporary directory, writes reviewed lesson sources there and invokes fixed Cargo commands with --offline --locked. Maintainers may run the dedicated verifier with --fetch once to populate Cargo's dependency cache from this exact lockfile. The browser continues to use the fixed external Playground prelude and does not send this manifest or select a dependency profile.
